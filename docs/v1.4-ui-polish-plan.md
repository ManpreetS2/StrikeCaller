# StrikeCaller v1.4 UI polish plan

This document describes the visual system **as implemented** in v1.4. It is not a backlog of extra product work.

## Primary action hierarchy

Home is not a grid of equal cards.

1. **Primary:** Start workout (featured workout hero, StrikeCaller red)
2. **Secondary:** For You remaining quick starts
3. **Then:** Progress from stored local history
4. **Then:** Compact tools (Customize, Daily, Demo, Builder)

Session remains a gym-first screen and is not a marketing surface.

## Home layout

- Brand line, version, Boxing / Muay Thai toggle
- Featured workout hero with **Start workout**
- Horizontal For You rail on small screens; grid on larger screens
- Progress: sessions, minutes, streak, rounds, combinations, frequent technique, sport breakdown
- Tools as compact chips, not competing CTAs

## Red vs blue

- **StrikeCaller red** (`--accent`): Start, End, brand marks
- **Electric blue** (`--accent-2`): navigation selected state and cinematic lighting only

Blue is not used as a second primary workout action.

## Navigation model

**Mobile:** Home · Train · Progress · More

**Desktop:** Home · Train · Progress · Builder · Settings

**More hub:** Daily, Builder, Stats, Settings, Learn, Demo, and Customize Workout

The active mobile More item covers Daily, Builder, Settings, Learn, Demo, and onboarding so those routes are not “lost” without a selected tab.

## Real progress metrics

Displayed values come from stored session history:

- session counts
- minutes trained
- streak
- rounds completed
- combinations completed
- frequent technique name
- Boxing / Muay Thai time breakdown

Empty history is shown honestly (`0` / `—` / “No sessions yet”).

## Session intentionally preserved

The session screen still uses:

- timer
- round
- current call
- next call
- combo path
- Pause / Repeat / Skip / End

v1.4 did not restyle this into a dashboard.

## Mobile behavior

- Bottom navigation stays visible outside Session
- Main content uses extra bottom padding so the nav does not cover tools
- Safe-area insets apply to the header, mobile nav, and session dock
- Featured Start workout is a full-width 44px-class target on small screens
- For You cards snap horizontally instead of shrinking into unreadably thin columns

## Desktop adaptation

- Top primary navigation replaces the bottom bar from the `lg` breakpoint
- Featured hero can sit beside the decorative visual
- For You becomes a four-column grid
- Start workout becomes a wide but not full-bleed button

## Accessibility considerations

- Native buttons, links, headings, and `aria-current` on navigation
- Theme controls expose `aria-pressed`
- Sport toggle uses `aria-pressed`
- Dialogs keep existing focus trap / Escape / restore behavior
- `prefers-reduced-motion` still reduces non-essential motion
- Decorative visuals stay `aria-hidden`
- Do not add ARIA where native HTML already names the control

## Why certain metrics are intentionally absent

StrikeCaller does not claim:

- strike accuracy
- punch speed
- power
- calories

because it has no sensor or camera measurement system. Those omissions are product integrity, not missing features. The coach calls combinations and records what was called and how long the athlete trained.
